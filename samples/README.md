## `quality-grid/`

`steps-04` · `steps-10` · `steps-20` · `steps-28` · `steps-40` · `steps-50`,
all `.png`, all 1024×1024. One prompt and one seed across the step sweep — the visual half of
the steps-vs-latency table in [`BENCHMARKS.md`](../BENCHMARKS.md). Written by
the benchmark harness, not by hand:

```bash
python benchmarks/harness.py --tag <image-tag> --only steps
```

Prompt and seed come from [`benchmarks/config.json`](../benchmarks/config.json)
(`a red fox in falling snow, cinematic lighting`, seed 42), so the grid is
reproducible without reading it out of a filename.

Same seed + same GPU type reproduces the image. Across GPU types, bf16 kernel
selection differs and pixels drift microscopically: the seed and dimensions
are the contract, not the bits.
